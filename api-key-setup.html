Getting an AI API key

AI features on this site run on your own API key from an AI provider. You create the key on their website, paste it once into Account Settings, and this site stores it encrypted so it can make requests on your behalf.

Which one should I pick?

  • Google Gemini Free tier — the only one you can use without paying. Start here.
  • Anthropic Claude Paid — small one-off trial credit, then pay-as-you-go.
  • OpenAI Paid — needs a payment method from the start.

Prices and free tiers change often. These notes were checked in August 2026 — always confirm on the provider's own pricing page.

Before you start

  • An API key is a password for your account with that provider. Treat it like one.
  • Usage is billed to you by the provider, not by this site. Set a spending limit in their console before you start.
  • This site stores your key encrypted and never shows it again after you save it — only the first few and last four characters, so you can tell which key it is.
  • Never paste a key into a chat, a screenshot, an email, or a GitHub issue.
  • If you think a key has leaked, revoke it in the provider's console and create a new one. Revoking is instant and free.

Google Gemini Free tier

Start here. Gemini is the only one of the three with an ongoing free tier, so you can use the AI features without a credit card. The others need you to pay.

  1. Sign in at aistudio.google.com/apikey with a Google account.
  2. Click Create API key, then choose or create a Google Cloud project.
  3. Copy the key. It will start with either AQ. or AIza — both are accepted here, see below.
  4. Paste it into the Google Gemini box on Account Settings and press Save.

If your key starts with AQ. instead of AIza

That's expected. Google is moving from older Standard keys (AIza…) to newer Authorization keys (AQ.…), and AI Studio now issues the new kind on most accounts. Google has said Standard keys will stop working after September 2026.

The catch: many developers report that AQ. keys are currently rejected by Google's own Gemini REST API with ACCESS_TOKEN_TYPE_UNSUPPORTED, which is a problem on Google's side, not with your key. So if you save an AQ. key here and it shows Unverified rather than Working, the key is kept anyway — press Re-check once Google has fixed it, and it will flip to Working without you re-entering anything.

Cost: Google's Flash models are free of charge on the free tier — that's what this site uses — with limits of roughly a few requests a minute and a few hundred a day. That's plenty for filling in vocab entries. Their more powerful Pro models are not part of the free tier. Heavier use needs billing enabled on the linked Cloud project; check ai.google.dev/pricing first.

Privacy: the free tier is not private. Google's own pricing page states that on the free tier your content is used to improve their products — so the words, sentences and notes you send get used for training. If you'd rather that didn't happen, enable billing on your Google Cloud project, which moves you to the paid tier where content is not used for training. This is Google's policy and applies wherever you use the key, not just on this site.

If it says Google denied access: the key usually has API or HTTP-referrer restrictions on it, or the Generative Language API isn't enabled on its project. Both are fixed in the Google Cloud console.

Anthropic Claude Paid

There is no free tier. New Console accounts are generally given a small one-off trial credit — enough to try things out — after which you have to buy credit. Anthropic doesn't publish the trial amount, so treat it as "a little, once".

  1. Sign in at platform.claude.com/settings/keys.
  2. Click Create key, give it a name you'll recognise later (e.g. japanese-vocab-site), and optionally set an expiry.
  3. The full key — starting with sk-ant- — is shown only once. Copy it now.
  4. Paste it into the Anthropic Claude box on Account Settings and press Save.

Cost: pay-as-you-go once any trial credit is used up. Add credit under Billing and set a monthly spend limit. Current prices: platform.claude.com pricing. Trial credit expires, so if you created an account a while ago and never used it, check the balance before assuming it's still there.

OpenAI Paid

There is no free tier and no starter credit — you must add a payment method before a key will do anything. If you only want to try the AI features, use Gemini instead.

  1. Sign in at platform.openai.com/api-keys.
  2. Click Create new secret key, name it, and optionally restrict it to a single project.
  3. The key — starting with sk-, often sk-proj- — is shown only once. Copy it now.
  4. Paste it into the OpenAI box on Account Settings and press Save.

Cost: pay-as-you-go from the first request. Add credit under Billing and set a usage limit. Prices: openai.com/api/pricing.

If it mentions quota: insufficient_quota means the key itself is fine but the account has no credit on it.

If saving doesn't work

When you press Save, this site makes one small test request to the provider to check the key really works before storing it. What the message means:

  • "rejected this key" — the provider says the key is wrong, revoked, or from a different account. Copy it again from their console; keys are easy to truncate when selecting by hand.
  • "That looks like a … key" — you've pasted a key for a different provider into the wrong box. Use the button offered to move it to the right one. Nothing was sent anywhere.
  • "couldn't be verified right now" — the provider was rate limiting or having an outage. Your key is saved; press Re-check in a minute to confirm it.
  • "rejected this key's type" — the Google AQ. key issue described above. The key is saved as Unverified; nothing is wrong with it on your end.
  • "Too many key checks" — there's a limit on how often keys can be tested. Wait a minute and try again.

Removing or replacing a key

Pressing Remove on Account Settings deletes this site's encrypted copy of your key. To replace a key, just paste the new one over the old — you don't need to remove it first.

Removing a key here does not revoke it at the provider. If the key may have been exposed, also delete it in the provider's own console — that's the only thing that actually stops it working.

If you delete your account on this site, remove your keys here first: account deletion doesn't currently reach the encrypted key storage.

What this site stores

  • Your key, encrypted, so nobody can read it out of storage.
  • A masked hint — the first six and last four characters — so you can tell which key is saved.
  • Whether it last passed a check, and when.

Your key is decrypted only on the server, only at the moment a request is made on your behalf. It is never sent back to your browser and there is no page or API on this site that will display it — including to the site owner.

Keys are stored per account, so logging in elsewhere carries your setup with you.
